# 小俠大亂鬥 Tiny Brawl Heroes

原創 2.5D 亂鬥格鬥遊戲（參考「小朋友齊打交」這類遊戲類型）：8 位小俠客、24 招必殺技（防禦 → 方向 → 攻擊），
撿球棒、丟石頭，最多 8 人混戰，也能兩個人用同一台鍵盤一起闖關打倒鋼鐵大王。Godot 4.7 網頁版。

線上玩：https://kevinchang0531.github.io/tiny-brawl-heroes/

- 1P：WASD 移動、J 攻擊、K 跳、L 防禦、U／I／O 必殺技
- 2P：方向鍵移動、`,` 攻擊、`.` 跳、`/` 防禦、`;` `'` `\` 必殺技
- 左右連按兩下跑步；Esc 暫停

角色、名稱、招式、美術、音樂皆為原創，沒有使用原作的角色或素材。本 repo 只放網頁匯出檔。
名字與分數存在你自己的瀏覽器裡。
